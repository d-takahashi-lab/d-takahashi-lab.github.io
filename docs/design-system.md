# 表示ルール

日本語・英語の本体7ページ（Toolsを含む）とツールのページで同じルールを使う。個別ページ・言語ごとに同じ役割の書体やサイズを変えない。旧デザイン比較ページは独立した過去の検討案。

## 書体

- ページの主見出し、セクション見出し（h1 / h2）：日本語はヒラギノ明朝または游明朝、英字はGeorgia。
- ヘッダーの研究室名：本文と同じゴシック体（英語はHelvetica Neue、ない端末ではArial）を、字間を広げて使う。上段の研究科名もゴシック体。
- 本文、人名、論文名、小見出し（h3 / h4）、住所、メール、ナビゲーション、フォーム：Arial／ヒラギノ角ゴ／游ゴシック。
- 年、日付、連番：本文と同じサンセリフ。桁幅を揃える。年はh2であってもデータとして扱う。
- 図中のラベル：サンセリフ。実験模式図はSVG内に閉じた注記・サイズを持つ。
- 強調は本文の太字、リンクはホバー・キーボードフォーカス・現在地で示す。別書体への切替で強調しない。

## 文字サイズと行間

| 役割 | PC | モバイル |
| --- | --- | --- |
| 主見出し | 36–48px | 36px |
| セクション見出し | 28px | 24px |
| 小見出し・論文名 | 20px | 18px |
| 本文 | 16px | 15px |
| ヘッダーのメニュー | 15px | 15px |
| UI・補足本文 | 14px | 14px |
| 注記・日付・図注 | 13px | 13px |
| 年見出し | 32px | 28px |

行間は文字の大きさではなく、内容の役割で決める。英語は欧文の字面に合わせ、どの段階も日本語より0.2狭くする。

| 役割 | 例 | 日本語 | 英語 |
| --- | --- | --- | --- |
| 文章 | 研究紹介・ニュース本文、ページ・セクションの説明文 | 2.0 | 1.8 |
| 情報 | ラベル付きの項目（研究分野・研究テーマ・連絡先）、住所、日付、書誌、図注、リンク列 | 1.85 | 1.65 |
| 名称・題名 | 小見出し（h3）、人名、論文名、建物名、ニュースの見出し一覧 | 1.6 | 1.4 |
| 構造見出し | ページ・セクション見出し（h1 / h2） | 1.5 | 1.3 |

- 値は `--leading-body` / `--leading-meta` / `--leading-title` / `--leading-heading` を参照し、数値を直書きしない。
- 日付と項目ラベル（「研究分野」「関連論文」など）は注記の13px。
- 字間は、日本語の明朝見出しだけ0.025em空ける。欧文と数字は詰めも空けもしない（0）。
- 太さは、名称・題名が500、年・時間などの数値データは見出し位置でも400、本文中の強調（自分の名前など）は600。
- 住所や建物名の「No. 3」「338-8570」のように、分かれると読めない語は `.nowrap` で改行させない。
- 例外：ヘッダーの研究室名はロゴと一体の組みとして、上下二行が同じ幅になる文字サイズ・字間を固定で持つ（日本語18px・0.16em、英語15px・0.03em。英語は研究科名の行と自然な幅が揃う大きさにして、単語間が引き伸ばされないようにする）。研究紹介の大きな番号（01〜04）は行間1。

## 配色・線・余白

背景 #ffffff、本文 #333333、見出し #171717、補足 #626262。境界線は #d6d6d2 の1px。入力欄の枠とリンク下線は #8a8a85。フォームの面は #f5f5f3。色は意味ごとの変数を参照する。

余白は4 / 8 / 12 / 16 / 24 / 32 / 48 / 64pxの共通段階を使う。本文領域の左右は7%、750px以下では6%。ページ見出しの開始位置、本文開始位置、セクション間隔、行の罫線は各ページで同じ基準を使う。画像の実寸・グリッド比率は内容に応じた寸法とする。

## ヘッダー・操作

左にロゴと研究室名をまとめる。ロゴは黒い六角形の中に、糖の六員環を中心とした雪の結晶を白抜きにしたもの（氷の結晶・糖の六員環・IDPを表し、6本の腕のうち1本がIDPの揺らぐ鎖）。ファイルは site-public/images/lab-mark-badge.svg、ファビコンも同じ図形。右にメニュー（15px）と言語切替（14px）。研究室名（18px）より小さく、本文に近い大きさにして、ロゴと研究室名が主役であることを保つ。英語の正式名は折り返さず一行。600px以下では「Stress & Adaptation Biology」と短縮表示し、ホームリンクのアクセシブル名は正式名を保つ。1100px以下ではナビゲーションをMenuボタンにまとめる。

全ページで同じリンク・下線・フォーカス表示を使用。入力欄は44px以上、文字16px（モバイルの自動ズームを避ける）。スライドショーのボタンは36px、明示的な一時停止を備える。

## 写真

毎回ランダムな開始写真・順序で、初期状態から6秒間隔の自動再生。動きを減らす設定ではフェードだけを省き、自動再生自体は有効。一時停止・前後移動を提供し、タブ非表示中や写真が画面外の間はタイマーを止める。復帰時は再開。キーボードで前後ボタンにフォーカスした場合は一時停止する。

研究模式図01・02も日英とも白背景。パネルは #f6f6f4、文字は #171717／#626262。寒冷・ヘミセルロースの青系、ペクチンの茶系は白地に合わせて濃くする。図の構造・注記は維持する。

## ページ上部・連絡先・地図

下層5ページは同じPageHeadingで「見出し行 → ページ内メニュー → 罫線」を生成する。研究の説明文は本文へ、年度は見出し行右の補足へ移し、見出し領域の構造を揃える。Worksのメニューは種別（すべて・原著論文・総説・書籍章）で、押すとその種別に絞り込み、選択中の項目に下線を引く。内容開始時の余白は共通の48px。スマートフォンでは日英ともロゴ行と操作行を分け、ヘッダーの高さも揃える。

メールはContactの「メールアドレスを表示」をクリックしてから表示する。静的HTMLとJavaScriptには平文アドレスを含めず、表示後はmailtoとコピーに対応する。これは単純な収集への抑止策であり、JavaScriptを実行する収集や、人手による取得を防ぐ認証機構ではない。教員プロフィールはContactへのリンクを使用する。

キャンパス案内図は大学公式建物配置図（https://www.saitama-u.ac.jp/access/map.pdf）を参照して作成した日英の簡略SVG。キャンパス全体の建物を描き、凡例の13棟に番号を付け、11番を黒で示す。来訪者が読みやすいよう北を上にし（公式図は南が上）、北矢印・縮尺省略の注記を設ける。建物の形は公式PDFから scripts/campus-map/build.py で生成する。最新の正式な配置・経路は出典PDFで確認できる。

## Tools

研究用ツールは /tools/ の一覧と、ツールごとのページ（日英）で公開する。ツールのページは「見出し（ツール名・版・更新日）→ 説明とデータを送信しない旨 → 計算 → 計算方法 → 引用のしかた → 免責事項・更新履歴」の順。入力欄・ボタンは他のフォームと同じく角丸なし・高さ44px以上・入力文字16px、主ボタンだけ黒地に白。PCでは入力（左）と結果（右）の2列、900px以下では1列。グラフは白地にサイトの黒・灰を使い、系列の色だけは区別のために色を付ける（1系列目は黒）。凡例は曲線のない側の上隅に置く。
