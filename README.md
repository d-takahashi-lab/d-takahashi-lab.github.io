# 生命適応科学研究室 — Astro

白背景・明朝体見出しを採用した、埼玉大学生命適応科学研究室の静的サイトです。

## 開発と確認

Node.js 24推奨（22.23.4以上）。

```sh
npm ci
npm run dev
npm run check
npm run build
npm run preview
```

本体はホーム・研究紹介・お知らせ・メンバー・研究業績・アクセスの6ページです。研究紹介には実験図と動画、メンバーには教員・学生のテーマ・卒業生、業績には47件の書誌情報を掲載しています。

## GitHub Pages

1. このフォルダの内容をリポジトリのルートに配置します。`.github/` を含めてください。
2. Settings → Pages → Source を **GitHub Actions** にします。
3. `main` へのpushで、型チェック・ビルド・公開を実行します。

`actions/configure-pages` のorigin/base_pathを使用するため、リポジトリ配下・ユーザーサイト・独自ドメインに対応します。独自ドメインはPages設定・DNSの設定に加え、必要なら **`site-public/CNAME`** にドメインを記載してください。

GitHub Pagesへの初回公開は2026-11-04に完了しました。公開URLは https://d-takahashi-lab.github.io/ です。既存ドメインのDNSは変更していません。

## トップのスライドショー

`src/data/slides.ts` に採用写真20枚の順序・キャプション・構図を記載しています。花・葉・草地と、雪・山・森・水辺の写真を組み合わせています。ページを開くたびに開始写真と順番をシャッフルし、開いた時点から6秒間隔で自動再生します。20枚が一巡した後も再シャッフルし、境目で同じ写真が続かないようにしています。前後移動・一時停止に対応。表示する写真と次の1枚を順次読み込むため、20枚を最初に一括取得しません。マウスを写真に重ねても自動再生は継続し、キーボードでコントロールに移動したときは自動再生が止まり、OSの「動きを減らす」設定ではフェードを使わず写真を切り替えます。JavaScript無効時も最初の写真が表示されます。

研究紹介の本文は、各テーマを背景・知見・解析・研究課題に分けて記載しています。模式図はSVGを直接編集できます。

写真タイトルとコレクション名は表示せず、操作ボタンと枚数のみを表示します。写真の説明は画像の代替テキストで提供します。研究本文や論文の表記は変更していません。ランダム順の検証は `work/tests/shuffle.test.mjs` で実施しています。

## News の投稿

公開サイトの `/admin/` にGitHub連携の投稿画面を生成します。ほかのMacからブラウザで利用できます。公開済みの記事の編集、タイトル・日付・本文・日英・写真・関連リンク、保存前プレビューに対応しています。

初回はGitHubアカウント（またはOrganization）、リポジトリ、公開ブランチを入力し、対象リポジトリだけに `Contents: Read and write` を付けたFine-grained personal access tokenで接続します。トークンはGitHub APIにのみ送信し、この画面のメモリ内で扱います。保存・ソースへの書き込みはしません。画面を閉じると再接続が必要です。トークンをチャットに貼り付ける必要はありません。

「掲載する」で保存すると記事と写真を一つのGitコミットで保存し、GitHub ActionsによるPages更新が始まります。ブランチ保護・Organizationのトークン承認などがある場合は、対応する権限の設定が必要です。競合時は上書きせずエラーにします。

公開用の下書きはブラウザのIndexedDBに保存し、GitHubに送信しません。下書きの内容はそのブラウザだけで利用できます。公開済みの記事は別のMacからも読み込めます。「下書き」で保存しても公開済みの内容は変わりません。日本語だけの記事は日本語版にだけ掲載されます。英語版にも掲載するには英語タイトル・本文を入力します。

このMacでソースを編集する場合は `npm run news` で `http://127.0.0.1:4322/` を起動します。下書き・未掲載写真・自動バックアップは非公開の `.news-editor/` に保存します。「サイトに反映」はローカルの生成処理です。公開サイトはGitHubへのpushで更新します。編集APIはlocalhostにだけ待ち受け、公開するdistには含めません。
